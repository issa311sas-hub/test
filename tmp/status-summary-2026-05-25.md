## 研究の変遷（v0.1 → v0.2 → v0.3）

| | v0.1（4/9） | v0.2（5/3） | **v0.3 確定版（5/20承認）** |
|---|---|---|---|
| **タイトル** | LLMの自己評価能力の検証 — 日本語 Calibration の実証分析 | LLMはハルシネーションを自己検知できるか | **プロンプト設計によるLLMのキャリブレーション性能向上** |
| **メインRQ** | 確信度と正答率は整合しているか？（記述的） | ハルシネーションを自己検知できるか？（検出的） | **確信度と正答率の整合性 + プロンプト設計で改善できるか？（測定＋改善）** |
| **サブRQ** | ①モデル ②タスク ③聞き方 ④日英 | ①検出精度 ②閾値 ③棄却 ④モデル ⑤ドメイン ⑥プロンプト | **①モデル ②タスク ③プロンプト方式(Verb.1S/2S, Ling.1S) ④日英** |
| **主指標** | ECE | AUROC, Precision/Recall | **ECE**（AUROC は補助） |
| **DEL** | 装飾的フレーミング | 研究の理論的骨格 | **周辺的注釈（発表に不採用）** |
| **ステータス** | 仮版 | 仮版 | **指導教員承認済み** |

### v0.2 が採用されなかった理由
指導教員が「ハルシネーション対処として calibration 測定は回りくどい」と指摘 → v0.2 で検出方向にピボットしたが、実際のゼミ発表では **calibration 測定＋プロンプト改善** の方向で承認された。v0.2 のハルシネーション検出フレーミングは発表に含まれなかった。
