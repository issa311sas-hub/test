# DEL チートシート（面談用カンペ）

> **用途**: 指導教員との面談前に 10 分で読み返すための最小限ノート
> **作成日**: 2026-04-11
> **前提**: DEL 入門書をまだ読んでいない段階での「最低限これだけ知っておけば会話できる」レベル

---

## 1. DEL とは（1 分で説明できるように）

**Dynamic Epistemic Logic（動的認識論理）** = エージェントの知識・信念が情報の流入によってどう変わるかを形式化した論理学。

- **静的な認識論理**: 「誰が何を知っているか」を記述する（Kripke モデル）
- **動的な認識論理**: 「新しい情報が来たら知識がどう変わるか」を記述する

---

## 2. 基本記号（面談で出てくる可能性が高いもの）

| 記号 | 読み方 | 意味 |
|---|---|---|
| `K_a φ` | 「エージェント a が φ を知っている」 | Knowledge |
| `B_a φ` | 「エージェント a が φ を信じている」 | Belief |
| `¬K_a φ` | 「a は φ を知らない」 | Ignorance |
| `[!φ]ψ` | 「φ が公共発表された後、ψ が成り立つ」 | Public Announcement |
| `K_a φ → φ` | 「知っていることは真」 | 真理性公理（T 公理） |

---

## 3. S5 と KD45 の違い（最重要）

| | S5（知識の論理） | KD45（信念の論理） |
|---|---|---|
| 基本演算子 | K（知識） | B（信念） |
| 真理性 | ✅ `K φ → φ` | ❌ 不要（信じていても偽かもしれない） |
| 正の内省 | ✅ `K φ → KK φ` | ✅ `B φ → BB φ` |
| 負の内省 | ✅ `¬K φ → K¬K φ` | ✅ `¬B φ → B¬B φ` |
| 整合性 | （T 公理から導出） | ✅ `¬B ⊥`（矛盾を信じない） |

**面談で使えるフレーズ**:
> 「LLM は知識ではなく信念を持つと考えるなら、KD45 系が適切だと思います。
> なぜなら、LLM の出力は必ずしも真ではないので、真理性公理は成り立ちません。
> ただし ECE で測定できるのは、まさにこの真理性公理がどの程度成り立つかです。」

---

## 4. 本研究との対応（これが核心）

```
LLM が質問に答える = エージェントが命題の真偽を判定する
確信度を表明する   = 信念の強さを数値化する
ECE が低い         = 真理性公理に近い（K φ → φ が成り立つ）
ECE が高い         = 真理性公理が破れている
AUROC が高い       = 負の内省が機能している（知らないことを知っている）
```

### 実験指標の DEL 的意味

| 指標 | DEL の公理 | 意味 |
|---|---|---|
| **ECE** | `K φ → φ`（真理性） | 高確信度が高正答率に対応するか |
| **AUROC** | `¬B φ → B¬B φ`（負の内省） | 確信度で正誤を識別できるか |
| **プロンプト感度** | `[!φ]`（動的更新） | プロンプト変更で信念がどう変わるか |
| **Brier Score** | 全体的な calibration | 信念体系の精度 |

## 5. 教員に聞くべき質問（優先順）

1. **「LLM を DEL のエージェントとして扱うフレーミングは妥当ですか？」**
   → これが NG なら calibration 単体の実証研究に戻す

2. **「S5 と KD45 のどちらを理論的ベースラインにすべきですか？」**
   → 個人的には KD45 が適切だと思うが、教員の意見を聞く

3. **「ECE を真理性公理の違反度と解釈する、という読み替えは論理学的に妥当ですか？」**
   → これが本研究の理論的貢献の核なので、教員の validation が欲しい

4. **「DEL-ToM (EMNLP 2025) はご存知ですか？本研究との関係をどう見ますか？」**
   → 教員が知っているなら、差別化の方針を一緒に練れる

5. **「DEL の学習で特におすすめの文献はありますか？」**
   → 教員が自分の講義ノートを持っているかもしれない
