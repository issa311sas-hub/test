## 発表で伝えた研究テーマ

**プロンプト設計による大規模言語モデル（LLM）のキャリブレーション性能向上に関する研究**

LLM が自分の回答の正確さを適切に認識できるようにすることで、ハルシネーション低減につながる可能性を検証する。

---

## 発表で説明した用語定義

| 用語 | 発表での説明 |
|---|---|
| LLM | 大量のテキストデータから学習した自然言語生成AI |
| ハルシネーション | AI が誤った情報を自信ありげに生成する現象 |
| キャリブレーション | モデルが出力する確信度と実際の正答率がどの程度一致しているかを示す指標 |

発表では「良い例（90%自信あり → 約90%正解）」と「悪い例（95%自信あり → 実際は誤答）」の対比で説明し、本研究は「良い例」に近づける方法を探ると述べた。

---

## 発表で伝えた研究背景

### 長期的ビジョン
- ハルシネーションの少ない高信頼 AI への貢献
- 一般利用者でも安全に利用可能な LLM 環境の実現

### 現状の課題
- LLM が誤情報を自信ありげに生成する [1]
- 一般利用者は誤情報を判別しづらい
- ハルシネーション対策は多数研究されているが決定的手法は未確立 [1]

### 本研究の位置づけ
- 特に**日本語環境**に注目
- 日本語タスクにおける LLM の自己評価能力を体系的に検証
- 確信度出力と実際の正答率の整合性を分析

### なぜ日本語環境に注目するか（3点を発表）
A. 英語タスクでの先行研究は存在するが、日本語に特化したキャリブレーション研究は見当たらない
B. 日本人は英語話者の割合が世界的に少なく、LLM への入力は基本的に日本語で行う場面が多い
C. 言語特性によってキャリブレーション性能に差が生じるかを検証することに価値がある

## 発表で伝えた重要先行研究

### 主要参考文献 [3]: Tian et al. 2023（EMNLP）

発表では1スライドを使い、以下を説明した:

- **背景**: 信頼できる予測システムには適切な確信度スコアが必要。事前学習のみの LLM は確信度が正答率に概ね一致していたが、RLHF 後は確信度が崩れる（過信傾向）
- **手法**: ChatGPT / GPT-4 / Claude 等の RLHF モデルから確信度を引き出す複数手法を比較
- **結果**: 内部 softmax 確率より「自信は〇〇%」と言葉で言わせる方が圧倒的に正確（ECE 約50%減）

### 発表で伝えた Tian 2023 の知見（6点）

| 結果 | 内容 |
|---|---|
| 直接聞くと ECE が約半分 | 内部確率より直接質問の方が大幅改善 |
| Top-k 候補で更に向上 | 複数候補を出させてから確信度を答えさせると精度向上 |
| 数値表現 > 言葉表現 | % や 0.0〜1.0 の数値の方が言葉より正確 |
| CoT は効果なし | Chain-of-Thought は確信度の精度に寄与せず |
| モデル間で能力差あり | Claude 2 が得意、Llama-2 はやや劣る |
| 補強研究 [4] | Xiong et al. 2024（ICLR）が複数モデルで同様の傾向を再確認 |

### 発表で提示したプロンプト3方式（Tian 2023 由来）

| 方式 | 説明 |
|---|---|
| Verb. 1S | 回答と確信度（0.0〜1.0）を一度にまとめて出力 |
| Verb. 2S | まず回答 → 別ターンで「その自信度は?」と質問 |
| Ling. 1S | 「ほぼ確実」「おそらく」など言葉で確信度を表現 |

### 発表で述べた「本研究との差分・拡張」
- 日本語環境で再検証
- 確信度の表現方法を体系的に比較
- 言語間（日/英）の差異も検証

### 発表で述べた研究意義（POINT）
> この先行研究は英語環境のみで検証されている。現在の LLM は入力を単に翻訳しているわけではなく高次元の非言語的処理を行うため、日本語で同様の結果が得られるかは未検証 — これが本研究の核心的問い。

## 発表で伝えた実験設計案

### 実験フロー
```
問題入力 → LLM（回答＋確信度出力） → 正答判定 → キャリブレーション評価
```

### 実験の基本方針
- 複数 LLM を比較
- 回答と確信度を同時収集
- タスクごとに評価方法を変更
- プロンプト条件を変更して比較

### 使用予定モデル
GPT / Claude / Gemini / Swallow 等（日本語特化）

### 発表で伝えた「現時点の課題」
- 評価指標（ECE 等）の選定
- 自然言語出力の正答判定
- LLM-as-a-Judge 導入可否 [6]

### 発表で伝えた「現時点の方針」
- 数学問題 → 完全一致判定
- 翻訳・自然言語 → 類似度評価を検討
- LLM による5段階評価手法も検討中
