## 3. 要旨（ダミー）

```
大規模言語モデル（LLM）は自信満々に誤答する傾向があり、
ユーザーの判断を誤らせる懸念がある。一つの対策として、
LLM自身に回答の確信度を表明させる手法が注目されているが、
日本語タスクにおける体系的な評価はほとんどない。本研究では、
GPT・Claude・Gemini・日本語特化モデル計4機種に対し、
常識・数学・歴史・翻訳の4ドメイン各50問を与え、
verbalized confidence の calibration を Expected Calibration
Error (ECE), Brier Score, AUROCで評価した。さらに
プロンプト方式と言語の影響も検証した。結果、[TBD]が
観察され、日本語LLM利用時の実務的指針を提示した。
```

## 5. 執筆ルール（統一感のため）

- 文体: 「である」調で統一
- 一人称: 「筆者」または主語なし（「本研究では...」）
- 時制: 既往研究は現在形（「Xは〜を示している」）、本研究の実施は過去形（「本研究では〜を行った」）
- 数値: 全角数字を使わない。半角英数字
- 図表番号: 「図1-1」「表3-2」のように章番号を含める
- 引用: 著者年方式（例: Kadavath et al., 2022）
