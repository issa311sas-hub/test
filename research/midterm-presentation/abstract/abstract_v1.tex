\section{研究背景}
% =====================================================================

大規模言語モデル（LLM）は教育・業務・日常生活へ急速に普及しているが，
「ハルシネーション」，すなわち誤情報を自信満々に生成する問題は未解決である\cite{ji2023survey}。
問題の本質は，モデルが示す確信度と実際の正答率の乖離にあり，
確信度が正答率と整合していれば（well-calibrated），利用者はそれをリスク判断の手がかりにできる。

キャリブレーション改善手法は大別して Post-hoc 補正（Temperature Scaling 等），
ファインチューニング，プロンプト設計の3系統がある。
GPT・Claude・Gemini のような商用 API は内部 logits やパラメータへのアクセスを提供しないため，
プロンプト設計のみが唯一実践可能な手段となる\cite{xie2024blackboxsurvey}。
先行研究\cite{tian2023just,xiong2024can}は，英語タスクにおいて
「言語化された確信度（verbalized confidence）」をプロンプトで引き出す方式が
内部 softmax 確率より優れた較正精度を達成することを示した（ECE を約50\%削減）。

Xue ら\cite{xue2025mlingconf}は日本語を含む5言語で verbalized confidence の
有効性を確認しており，「日本語での検証が全く存在しない」わけではない。
しかし同研究には (1) 確信度の聞き出し方が1手法のみで方式間の比較がない，
(2) 英語発の問題を機械翻訳したデータセットのみを使用している，
(3) 検証モデルが GPT-3.5・Llama-3.1 という旧世代に限られる，
という3つの限界があり，日本語ネイティブなタスク上での方式間比較・現行世代モデルでの
再現性検証は行われていない。

\section{研究目的}
% =====================================================================

本研究の目的は，\textbf{日本語ネイティブなタスクにおいて確信度プロンプト方式
（Verb.1S / Verb.2S / Ling.1S）の違いがキャリブレーション性能にどのような差をもたらすか}，
また\textbf{その効果が現行世代の商用 LLM でも再現されるか}を実証的に検証することである。

\textbf{メイン RQ}：日本語ネイティブなタスクにおいて，確信度プロンプト方式の違いは
LLM の較正精度（ECE・Brier Score）にどのような差をもたらすか。また現行世代の商用 LLM
（GPT-4o・Claude Sonnet 4.6・Gemini 2.x 等）でもその効果は再現されるか？

\textbf{サブ RQ}：モデル間・タスクドメイン間・日英言語間で
較正性能の改善パターンにどのような差があるか？

これまでの取り組みでは英語中心・少数プロンプトでの予備的な ECE 比較にとどまっていたが，
本研究は日本語4ドメイン・3方式・複数モデルでの体系的な検証へと発展させるものであり，
今後の本実験・考察へ直結する内容として位置づけている。

% =====================================================================
\section{研究の方針}
% =====================================================================

上記の RQ を検証するため，複数の商用・国産 LLM に対して日本語タスク上で
3種類の確信度プロンプト方式を適用し，較正精度を比較する実験を計画している。
具体的な条件は以下のとおりである。

\textbf{モデル}：GPT-4o，Claude Sonnet 4.6，Gemini 2.x，Swallow（4〜6 モデル）。

\textbf{データセット}：日本語4 ドメイン × 250 問 = 計 1,000 問
（MGSM・JCommonsenseQA・JMMLU・FLORES-200，いずれも日本語ネイティブに構築されたデータセット）。

\textbf{プロンプト方式}（3 方式を比較）：
Verb.1S（回答と確信度を同時出力），
Verb.2S（Turn1 で回答，Turn2 で確信度を別途質問），
Ling.1S（言語表現5段階を数値マッピング）。
いずれもプロンプト設計のみで実現し，logits・再学習は不要である。

\textbf{評価指標}：

\begin{align}
  \text{ECE} &= \sum_{m=1}^{M} \frac{|B_m|}{n} \left|\text{acc}(B_m) - \text{conf}(B_m)\right| \\
  \text{BS} &= \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i)^2
\end{align}

主指標は ECE・Brier Score・AUROC とする。補足的な切り口として，
Murphy 分解\cite{murphy1973vector}（$\text{BS} = \text{REL} - \text{RES} + \text{UNC}$，
Bröcker\cite{brocker2009reliability} により任意の Proper Scoring Rule へ一般化済み）を用いて
較正精度（REL）と識別能力（RES）を分離することも試みる。信頼区間には
Ferro \& Fricker 分散推定\cite{ferro2012decomposition}を用いる。

\textbf{正答判定}：数学（MGSM）は正規化完全一致，
常識・知識（JCommonsenseQA・JMMLU）は選択肢ラベル一致，
翻訳（FLORES-200）は COMET スコア閾値（50文の人間判定で F1 最適化）とする。

\textbf{検証仮説}：H1（Verb.2S は Verb.1S より ECE を改善する），
H2（Ling.1S は数値表現方式より改善幅が小さい），
H3（改善幅はドメインにより異なる），
H4（日本語での改善幅は英語より小さい：MlingConf の実測でも
Verb.手法の ECE は英語より日本語で悪化する傾向が複数タスクで観測されている）。

\section{現在の進捗}
% =====================================================================

現時点までに，以下の準備を完了している。

第一に，データセットの選定と正答判定方法の設計を行った。
4ドメイン（数学・常識・知識・翻訳）それぞれについて使用するデータセットを決定し，
各ドメインの正答判定基準（数値の完全一致，選択肢ラベル一致，翻訳品質スコアの閾値等）を
先行研究の手法と比較したうえで確定した。

第二に，3方式（Verb.1S/Verb.2S/Ling.1S）それぞれについて，
4ドメイン分のプロンプトテンプレートを作成した。
Verb.2S は2ターン構成（まず回答のみを取得し，別ターンで確信度のみを質問する）
となるため，会話履歴を保持したまま2回目の問い合わせを行う処理を実装している。
また，モデルの出力から回答と確信度を自動的に取り出す解析処理，
および言語表現（「ほぼ確実」等）を数値（0.0〜1.0）に変換する対応表も実装済みである。

第三に，ECE・Brier Score・AUROC を計算するプログラムを実装し，
既知の性質を持つ人工データ（確信度と正答率が完全に一致するように生成したデータ）を用いて，
計算結果が理論値と一致することを数値的に確認した。
補足的な切り口として検討している Murphy 分解についても同様に実装・検証済みであり，
$\text{BS} = \text{REL} - \text{RES} + \text{UNC}$ という等式が
（区間分割に起因する既知の誤差の範囲内で）成立することを確認している。

第四に，先行研究の再調査を行い，MlingConf\cite{xue2025mlingconf} が日本語を含む
多言語で確信度手法の検証を既に行っていることを確認した。この結果を踏まえ，
本研究の新規性の主張を「方式間比較・日本語ネイティブデータセット・現行世代モデル」
の3点に絞り込んで精緻化した。

一方で，実際の API を用いた実験は未実施であり，
上記の準備をもとにした実測データはまだ得られていない。

\section{今後の予定}
% =====================================================================

今後はまずパイロット実験（少数モデル・少数問題）を実施し，
プロンプトテンプレートの解析成功率や API 呼び出しの安定性など，
スクリプトの動作確認を行う。この段階で出力形式の解析に問題が見つかった場合は，
プロンプトの指示文や出力形式の指定を修正したうえで再度確認する。
動作確認が完了した後，複数モデル×3方式×大規模な問題数で本実験を実施し，
確信度プロンプト方式間の差と現行モデルでの再現性を検証する。

本実験で得られる結果のパターンとしては，主に次の3通りが想定される。
(a) プロンプト方式間で較正性能に明確な差が見られる場合は，統計検定によりその差の
有意性を確認したうえで，どのような設計上の違いがその差を生んでいるかを考察する。
(b) 方式間に有意な差が見られない場合は，「聞き方の違いは較正性能に大きく影響しない」
という知見自体を報告し，先行研究（MlingConf 等）の結果と突き合わせて解釈する。
(c) モデルによって効果の出方が異なる場合（例えば一部のモデルでのみ改善が見られる場合）は，
モデルの指示追従能力や学習データの違いとの関連を考察する。
いずれの結果になっても，何らかの形で報告可能な知見として整理する方針である。

実験データが十分に得られた場合は，Murphy 分解による REL/RES 分離分析を
補足的な考察として追加し，較正性能の改善が較正精度（REL）と識別能力（RES）の
どちらに由来するかという観点からも結果を検討する。
これらの実験・分析を踏まえ，続いて各章の草稿を作成し，
指導教員の確認を経て最終稿をまとめたうえで卒業論文として提出する予定である。
本研究はこれまでに確立した評価基盤を土台としつつ，日本語ネイティブタスクでの
方式間比較という新たな軸を加えることで，今後の本実験・考察に直接接続する構成となっている。
