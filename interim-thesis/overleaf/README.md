# Overleaf にそのままインポートできる一式

研究室のテンプレート（`jreport`・1 段組み・章ごとのフォルダ）に，
`interim-thesis/` の原稿を流し込んだもの．**このフォルダを zip にして
Overleaf にアップロードすれば，そのままコンパイルできる．**

## Overleaf での操作

1. New Project → Upload Project → この一式の zip を選ぶ
2. Menu を開き，以下を確認する
   - **Compiler**: `LaTeX`（`latexmkrc` で platex + dvipdfmx が指定されている）
   - **Main document**: `main.tex`
3. Recompile

参考文献は `thebibliography` 形式で書いてあるため，**BibTeX の実行は不要**．
1 回のコンパイルで出る．

## 構成

テンプレートの構造をそのまま使っている．

| ファイル | 内容 | 由来 |
|---|---|---|
| `main.tex` | 本体 | テンプレート（2 行だけ追加．下記） |
| `latexmkrc` | コンパイル設定 | テンプレートのまま |
| `title.tex` | 表紙 | 差し替え |
| `abstract/abstract.tex` | 中間報告概要 | 原稿から生成 |
| `chapter1/index1.tex` | 第1章 序論 | 原稿から生成 |
| `chapter2/index2.tex` | 第2章 関連研究 | 原稿から生成 |
| `chapter3/index3.tex` | 第3章 設計方針 | 原稿から生成 |
| `chapter4/index4.tex` | 第4章 実装 | 原稿から生成 |
| `chapter5/index5.tex` | 第5章 予備実験 | 原稿から生成 |
| `chapter6/index6.tex` | 第6章 考察 | 原稿から生成 |
| `chapter7/index7.tex` | 第7章 今後の方針 | 原稿から生成 |
| `reference/reference.tex` | 参考文献（25 件） | 原稿から生成 |
| `figure/` | 図 5.1・5.2 | 実験結果から |
| `references.bib` | BibTeX 版（使う場合のみ） | — |

## テンプレートへの変更

`main.tex` に 2 行だけ足してある．それ以外は変えていない．

```latex
\usepackage{tabularx}  % 本文の表で使用
\usepackage{url}       % 参考文献の URL で使用
```

冒頭のコメントも年度に合わせて書き換えた．

## 本文幅への対応

1 段組みの本文幅（`30em + 50pt`）を超えないよう，表の組み方を変えている．

- 長い文を含む列がある表（3.3，3.4，4.1，4.2，7.1）は `tabularx` の `X` 列で
  折り返す．`l` 列は折り返さないため，そのままでは本文幅を超える．
- 列数が多く数値が並ぶ表 5.1（9 列）は，テンプレートの流儀に合わせて
  `\scalebox{0.93}` で縮めている．折り返すと数値が読みにくくなるため．
- 長いファイル名は区切り記号のあとで改行できるようにしている．

## 原稿を直す場合

**このフォルダの `.tex` を直接編集しないこと．** 次に変換したとき消える．

原稿は `interim-thesis/*.md` にある．直したあと，

```
cd interim-thesis
python md2tex.py
```

を実行すると，このフォルダが作り直される．Overleaf 側で最終的な微調整を
する分には，もちろん直接編集してかまわない．

## コンパイル前に確認してほしいこと

**手元に TeX 処理系が無いため，コンパイルは検証できていない．**
以下が出た場合の対処を挙げておく．

- **`Undefined control sequence \ps@bothstyle`**
  テンプレートの `main.tex` 96 行目付近に `\pagestyle{bothstyle}` があるが，
  テンプレートが定義しているのは `testheadings` であり，`bothstyle` は
  定義されていない．元のテンプレートのままなので手を入れていない．
  エラーになる場合は `\pagestyle{plain}` に変えるか，行ごとコメントアウト
  する．**この 1 行以外はテンプレートを変更していない．**
- **図や表の位置が本文から離れる**
  `[htbp]` を指定している．離れすぎる場合は該当箇所で調整する．
- **表 5.1 がまだはみ出す**
  `\scalebox{0.93}` の値を下げる（0.85 など）．
- **第3章のプロンプト例が崩れる**
  `verbatim` で組んでいる．日本語が等幅フォントで崩れる場合は，
  テンプレートが読み込んでいる `listings` か `ascmac` の枠に変える．
