# 要旨

大規模言語モデル（Large Language Model，以下 LLM）は，誤った内容を正しい
内容と変わらない語調で出力する．利用者は出力の語調から正しさを推し量れず，
どの回答を優先して検証すべきか判断しにくい．この問題に対し，モデル自身に
回答への確信度を言語で表明させ，その確信度が実際の正答率とどの程度一致するか
を測る研究が進められている．一致の度合いは較正（calibration）と呼ばれる．

既存研究の多くは英語のタスクを対象としており，日本語での検証は限られている．
また確信度をどのように尋ねるかによって結果が変わることは指摘されているものの，
日本語のタスクで複数の尋ね方を同一条件のもとで比較した報告は少ない．本研究は，
日本語タスクにおいて確信度の引き出し方が較正に与える影響を明らかにすることを
目的とする．

本論文では，回答と確信度を同時に尋ねる方式（Verb.1S），回答を得てから確信度を
別のターンで尋ねる方式（Verb.2S），確信度を数値ではなく言語表現で答えさせる
方式（Ling.1S）の 3 方式を設計し，ECE（Expected Calibration Error），
Brier Score，AUROC，および Murphy 分解を計算する評価基盤を実装した．

予備実験として，日本語版 MGSM の 250 問を claude-sonnet-4-6 に与え，3 方式を
比較した．Ling.1S は ECE，Brier Score，AUROC，正答率のいずれにおいても他の
2 方式より劣り，この差は問題の再抽出による 95% 信頼区間で支持された．一方，
Verb.1S と Verb.2S の差はすべての指標で信頼区間が 0 を含み，250 問では判定
できなかった．

最も顕著だったのは，3 方式のいずれにおいても確信度が 0.9 以上に強く偏った
ことである．平均確信度は 3 方式とも 0.91 から 0.94 の範囲にあり，尋ね方を変えて
も分布はほとんど動かなかった．方式によって変化したのは主に正答率の側である．
この偏りのもとでは ECE の値が平均確信度と平均正答率の差に近づき，較正の水準と
正答率の高低を区別しにくい．3 方式は回答そのものが異なるため，較正の差のみを
取り出すには回答を固定した比較が必要であり，本論文ではこの分離を行えていない．

今後は，この偏りを対象としたプロンプト設計と，回答を固定した較正の比較に
取り組む．
