# 第6章 考察

本章では第 5 章の結果を解釈する．6.1 節で確信度が上端に集中する現象を，
6.2 節でその現象が評価指標に与える影響を述べる．6.3 節で Ling.1S の正答率
低下について考察し，6.4 節で本研究の限界を整理する．

## 6.1 確信度の上端への集中

予備実験で最も顕著だったのは，3 方式のいずれにおいても確信度が 0.9 以上に
集中したことである．Ling.1S では 5 段階の選択肢を与えたにもかかわらず 81%
が最上位に集中し，実質的に 1 段階しか使われていなかった．平均確信度は
3 方式とも 0.91 から 0.94 の範囲にあり，引き出し方を変えても分布はほとんど
動かなかった．

この現象には 2 つの側面がある．

第一に，モデルが自信過剰であることである．表 5.2 に示したとおり，平均確信度
は平均正答率を 0.049 から 0.183 上回っている．自信過剰は Xiong ら [10] も
報告しており，本研究の結果はそれと整合する．

第二に，より重要な点として，**確信度の解像度が失われていることである**．
較正が有用であるためには，確信度が問題によって変化し，難しい問題では低い値，
易しい問題では高い値をとる必要がある．確信度がほぼ一定であれば，どの問題を
検証すべきかという利用者の判断に寄与しない．本研究が対象とする 3 方式は，
いずれもこの解像度を引き出せていない．

ただし，確信度が一定であってもその値が正答率に一致していれば，ECE の上では
良好な較正と評価される．較正が良いことと確信度が有用であることは別である．
この点を捉えるには AUROC や RES のような識別の指標が必要になる．

なお，本実験の対象は算数の文章題であり，モデルにとって比較的得意な領域で
ある．正答率が 72% から 87% と高いため，高い確信度が集中すること自体は
不自然ではない．より難しい領域や，モデルが誤りやすい領域でも同じ分布に
なるかは確認できていない．この点は今後の課題である．

## 6.2 ECE の退化と Murphy 分解の必要性

6.1 節で述べた分布は，評価指標の解釈に直接影響する．

表 5.1 の ECE と，表 5.2 の「平均確信度と平均正答率の差」を比較すると，
両者はほぼ一致している．Verb.1S では 0.0874 と 0.087，Verb.2S では
0.0558 と 0.049，Ling.1S では 0.1826 と 0.183 である．

これは偶然ではない．3.4.1 項で述べたとおり，ECE は確信度を区間に分割し，
各区間の平均確信度と正答率の差を重みづけて平均する．確信度がほぼ 1 つの
区間に集中していれば，使われる区間は実質的に 1 つになり，ECE は全体の平均
確信度と全体の正答率の差に近づく．すなわち **ECE が較正の指標として機能
せず，正答率の高低をほぼそのまま反映する量に退化している**．

この退化には実害がある．表 5.1 で ECE の順位は Verb.2S，Verb.1S，Ling.1S の
順であり，これは正答率の順位を裏返したものと一致する．したがって
「Ling.1S は較正が悪い」と ECE のみを根拠に主張すると，「正答率が低いだけ
ではないか」という指摘に答えられない．較正の質と正答率の高低が分離できて
いないためである．

この問題は Murphy 分解によって回避できる．3.4.3 項で述べたとおり，UNC は
全体の正答率のみで決まる．実際，Ling.1S の UNC は 0.1998 であり，正答率
0.724 から計算した $0.724 \times (1-0.724) = 0.1998$ と一致する．すなわち
Brier Score に含まれる正答率由来の成分は UNC として分離されており，
較正の質は REL に現れる．

表 5.4 に示したとおり，REL においても Ling.1S と他の 2 方式の差は信頼区間が
0 を含まなかった．正答率の寄与を取り除いてもなお較正が劣るということであり，
上述の指摘に対する反論となる．

この経験から，較正の評価において ECE を単独で用いることは避けるべきである
と考えられる．確信度の分布が偏っている場合，ECE は較正ではなく正答率を
測っている可能性がある．少なくとも，ECE を報告する際には確信度の分布を
併せて示し，平均確信度と平均正答率の差と比較できるようにすべきである．

当初の研究計画では Murphy 分解を補助的な位置づけとしていたが，予備実験の
結果を踏まえ，主要な評価手段として扱うこととした．

## 6.3 Ling.1S における正答率の低下

Ling.1S の正答率は 72.4% であり，Verb.1S の 84.4%，Verb.2S の 87.2% を
12 ポイントから 15 ポイント下回った．この差は信頼区間が 0 を含まず，標本の
揺らぎでは説明しにくい．

注目すべきは，3 方式が解く問題も対象モデルも同一であり，違いは確信度の
尋ね方だけである点である．**確信度の表明形式を変えただけで，回答そのものの
正しさが変化している**．確信度の引き出しは回答に対して中立な操作であると
暗黙に仮定されがちだが，この結果はその仮定が成り立たない場合があることを
示している．

原因は本研究では特定できていない．考えられる説明として，5 つの言語表現を
提示することでプロンプトが長くなり，問題そのものへの注意が相対的に薄れた
可能性がある．また，言語表現を選ぶという追加の作業が，解答の生成に割かれる
処理を圧迫した可能性もある．いずれも推測の域を出ない．

この点を確かめるには，回答のみを求める条件と比較する必要がある．確信度を
一切尋ねずに同じ 250 問を解かせ，その正答率を基準とすれば，各方式が正答率を
どの程度押し下げるかを測れる．この条件は予備実験に含めていなかった．本実験
では基準条件として追加する．

## 6.4 本研究の限界

現時点での限界を整理する．

**対象が 1 モデル・1 領域に限られる．** 予備実験は claude-sonnet-4-6 と
算数の文章題のみを対象としている．他のモデルや他の領域で同じ傾向が得られる
かは確認できていない．したがって本論文の結果から一般的な結論は導けない．

**データセットが日本語で作成されたものではない．** 3.3.2 項で述べたとおり，
MGSM は英語で作成された問題を人手で翻訳したものである．日本語タスクにおける
較正を論じるには，日本語で作成されたデータセットによる追試が必要である．

**単一試行である．** 温度を 0 としているが，同一条件を複数回実行した場合の
再現性は確認していない．問題の再抽出による信頼区間は求めたが，これはモデル
出力自体の揺らぎを評価するものではない．

**言語表現と数値の対応づけが恣意的である．** 表 3.1 の割り当ては研究者が
定めたものであり，この割り当てが変われば Ling.1S の ECE と Brier Score は
変化する．REL と AUROC も影響を受ける．Ling.1S の評価は，この対応づけを
前提とした条件付きのものである．対応づけを変えた場合の感度を調べる必要が
ある．

**確信度の取得に失敗した 2 問の扱いを検討していない．** Verb.1S において
250 問中 2 問で確信度が取得できなかった．これらを指標の計算から除外して
いるが，除外が結果に与える影響は評価していない．割合は 0.8% と小さいものの，
除外された問題が特定の性質を持つ可能性は否定できない．

**1 段階方式と 2 段階方式の比較が未決着である．** 5.4.4 項で述べたとおり，
248 問では判定できなかった．この問いに答えるには問題数を増やす必要があるが，
MGSM の日本語版は 250 問が上限であり，別のデータセットを併用しなければ
ならない．
