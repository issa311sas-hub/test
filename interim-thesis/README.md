# 夏の中間報告（中間論文）ドラフト

卒業論文フォーマットに向けた中間論文のドラフト．Overleaf への貼り付けは
手作業で行う前提のため，ここでは TeX ではなく Markdown のメモとして書いて
いる．数式は TeX 記法のまま書いてあるので，`$$ ... $$` の中身はそのまま
コピーできる．

## 章立ての根拠

添付された昨年度の中間論文（7422085）および卒業論文 3 編と同じ骨格を採用
している．先生の要件である「序論，関連研究，設計方針を中心に」「実装および
実験も行えたらその内容も記載」に対応させ，第 3 章を最も厚くした．

第 7 章を「結論」ではなく「今後の方針」としているのは，中間報告の時点で
結論を出せる段階にないためである．過去の卒業論文では第 7 章が「結論」に
なっているので，卒業論文に発展させる際に差し替える．

## 執筆時の注意

`00-style-guide.md` に，過去論文から抽出した表記規則と文体の規約をまとめて
ある．とくに句読点は **「，」「．」** であり，「、。」ではない．Markdown の
まま貼り付けると本文の句読点はそのまま使えるが，見出しの記法や表の記法は
TeX に直す必要がある．

## レビューを依頼する際の観点

外部のレビュー（Codex 等）に出す場合，以下を判定基準として渡すとよい．

1. `00-style-guide.md` の「3. AI が書いた文章に見えないために」に挙げた
   表現が混入していないか．
2. 第 5 章の数値と，`results/` 以下の実測値が一致しているか．
3. 統計的に支持されない差を，支持されているかのように書いていないか．
   とくに Verb.1S と Verb.2S の比較（5.4.4 項）．
4. 第 2 章で引用した先行研究の記述が，その論文の主張と合っているか．
   とくに MlingConf の扱い（2.3 節）と ADVICE の扱い（2.2.4 項）．
5. 各章の冒頭に道案内の段落があり，末尾に「本章のまとめ」があるか．

## 改訂の経緯

初版（コミット `b9ff4a2`）に対し，Codex によるレビュー
（`reviews/interim-thesis-review.md`）を受けて全面的に改訂した．主な変更は
以下の 3 点である．

1. **採点処理の不具合を修正し，全数値を差し替えた．** 正解側の桁区切り
   カンマを除去していなかった件と，応答中で最初に現れた回答を採っていた
   件の 2 件．経緯は `research/experiment/rescoring-2026-09-16.md` に記録．
2. **Murphy 分解に関する主張を撤回した．** 初版は「REL を用いれば較正と
   正答率を分離できる」と述べていたが，REL も各区間の正答率を含むため
   分離の手段にならない．再採点後は REL による差の検出もできなかった．
   分解は補助的な情報として位置づけを下げ，分離には回答を固定した比較が
   必要であることを第 6 章・第 7 章に明記した．
3. **先行研究の記述を訂正した．** MlingConf の比較範囲，Tian らの尺度と
   比較対象，Dai らの公開年，LLM-jp の引用先など．
