# 第2章 関連研究

本章では，本研究に関係する既存研究を 4 つの観点から概観する．2.1 節では較正を
測る指標の定義とその起源を述べる．2.2 節では LLM に確信度を言語で表明させる
手法について述べる．2.3 節では多言語環境での較正を扱った研究を述べる．
2.4 節では較正を改善する手法を，プロンプトによるものと学習によるものに分けて
述べる．2.5 節で本研究の位置づけを示し，2.6 節で本章をまとめる．

## 2.1 較正の評価指標

### 2.1.1 較正という概念と ECE

較正は，モデルが出力する確信度と実際の正答率の一致を指す概念であり，もとは
気象予報の評価から発展した．機械学習の分野では Guo ら [8] が広く知られる．
Guo らは，分類精度の高い深層ニューラルネットワークが，層の浅い従来のモデルに
比べてむしろ較正が悪化していることを示した．すなわち精度と較正は別の性質で
あり，精度が高いモデルが自動的に信頼できる確信度を出すわけではない．

較正の程度を測る指標として広く用いられるのが ECE（Expected Calibration
Error）である．ECE は確信度の値域をいくつかの区間に分割し，各区間における
平均確信度と実際の正答率の差を，区間に含まれる標本数で重みづけて平均する．
値が小さいほど較正が良い．区間分割を用いる推定法は Naeini ら [11] に基づく．

ECE は解釈しやすい一方で，区間の数と確信度の分布に結果が依存する．確信度が
狭い範囲に集中していると，実質的に少数の区間しか使われず，指標としての
分解能が落ちる．この性質は本研究の予備実験で実際に問題となった．

### 2.1.2 Brier Score と Murphy 分解

Brier Score は，確信度と正誤（0 または 1）の二乗誤差の平均であり，較正と
識別能力の両方を同時に評価する指標である．ECE と異なり区間分割を必要とせず，
確率予測に対する厳密な採点規則（proper scoring rule）である．

Murphy [12] は Brier Score を 3 つの成分に分解できることを示した．すなわち
信頼度（reliability），識別度（resolution），不確実度（uncertainty）である．
信頼度は確信度と正答率のずれを表し，較正の質のみを反映する．識別度は，
モデルが正答する問題と誤答する問題を確信度によって区別できている程度を表す．
不確実度は全体の正答率のみから決まる定数であり，モデルの振る舞いとは無関係に
タスクの難しさを反映する．

この分解は，較正の質とタスクの難しさを分離できる点で本研究にとって重要である．
2 つの手法を比べたとき Brier Score に差があっても，それが較正の差なのか
正答率の差なのかは Brier Score だけでは判別できない．分解によって，正答率に
由来する不確実度を切り離し，較正のみを表す信頼度で比較できる．分解の
実務上の扱いについては Ferro ら [13] や Pohle [14] に整理がある．

### 2.1.3 AUROC

AUROC は，確信度を閾値として正答と誤答を判別したときの識別性能を表す．
0.5 が無作為な判別に相当し，1.0 が完全な判別に相当する．AUROC は確信度の
絶対的な水準を評価せず，順序のみを評価する．すなわち，すべての確信度を
一律に 0.1 下げても AUROC は変化しない．較正が悪くとも識別はできている，
という状況を捉えられるため，ECE と併用されることが多い．

## 2.2 確信度の言語による表明

### 2.2.1 内部確率を用いる手法との対比

LLM の確信度を得る素朴な方法は，生成されたトークンの対数確率を用いることで
ある．しかし Tian ら [7] は，人間のフィードバックによる強化学習（RLHF）で
調整されたモデルでは，この対数確率に基づく較正が崩れていることを指摘した．
また商用の API では対数確率が取得できない場合も多く，実用上の制約もある．

### 2.2.2 verbalized confidence

これに対し，モデル自身に確信度を言語で答えさせる手法が提案されている．
Lin ら [6] は，モデルが不確実性を言葉で表現するよう学習させられることを示し，
Kadavath ら [5] は，モデルが自身の回答の正しさをある程度予測できることを
報告した．

Tian ら [7] は，プロンプトのみで確信度を引き出す複数の方式を比較し，
0 から 100 の数値で答えさせる方式が良好な較正を示すこと，また verbalized
confidence が対数確率に基づく手法より良い較正を示すことを報告した．同研究では
言語表現で答えさせる方式や，複数の候補と確率を同時に出させる方式も検討されて
いる．本研究が比較する 3 方式は，この研究の枠組みを踏まえたものである．

Xiong ら [10] は確信度の引き出し方を体系的に整理し，プロンプトの与え方に
よって結果が大きく変わること，そして LLM が一貫して自信過剰である傾向を
示した．Yang ら [15] も verbalized confidence の性質を調べ，プロンプトの
定式化に対する感度を報告している．

### 2.2.3 確信度のスケールと表現形式

確信度をどのような尺度で答えさせるかも結果に影響する．Dai ら [16] は，
0 から 100 の尺度で答えさせると確信度が切りのよい数値に集中することを指摘し，
より粗い尺度のほうが良好な結果を示す場合があると報告している．
また Mielke ら [17] は，
対話エージェントの過信を言語表現による較正で緩和する手法を示しており，
数値ではなく言語で不確実性を伝える方向の研究もある．

本研究が Ling.1S として言語表現による方式を含めるのは，実用面での意味が
あるためである．利用者に提示する際には「0.85」という数値より「かなり自信が
ある」という表現のほうが直感的に伝わる可能性がある．一方で，言語表現は
段階数が限られるため確信度の解像度が落ちる恐れもある．この得失を実測で
確認する必要がある．

### 2.2.4 自信過剰の原因に関する知見

Seo ら [18] は ADVICE と呼ばれる手法を提案し，確信度の推定が回答の内容に
依存していないことが自信過剰の主要因であると指摘した．すなわちモデルは，
自分が何と答えたかを踏まえずに確信度を述べている場合がある．この知見は，
回答を得たうえで改めて確信度を尋ねる 2 段階方式（Verb.2S）を設計する
根拠となる．回答を明示的に提示したうえで確信度を問えば，回答内容に依存した
確信度が得られると期待される．

ただし ADVICE 自体はモデルの重みを更新する手法であり，本研究が対象とする
プロンプトのみの手法ではない．本研究が引用するのは，自信過剰の原因に関する
診断的な知見に限られる．

## 2.3 多言語環境における較正

多言語での較正を扱った研究として，Xue ら [9] の MlingConf がある．同研究は
英語，日本語，中国語，フランス語，タイ語の 5 言語を対象に，内部確率を用いる
手法，p(True) を用いる手法，verbalized confidence の 3 手法を比較した．

MlingConf は日本語を対象に含む数少ない研究であり，本研究にとって最も近い
先行研究である．同研究の報告によれば，言語によって較正の質は異なり，英語での
較正が他言語より良好な傾向がある．たとえば GPT-3.5 を用いた TriviaQA では，
英語の ECE が 16.52 であるのに対し日本語では 34.49 と報告されている．

ただし MlingConf には本研究の関心から見て 3 つの制約がある．第一に，比較
されているのは verbalized confidence の単一の方式であり，引き出し方の違いに
よる比較は行われていない．第二に，用いられたデータは英語で作成された問題を
翻訳したものであり，日本語として自然な問題ではない．第三に，対象モデルは
GPT-3.5 と Llama-3.1 であり，より新しい世代のモデルは含まれていない．

## 2.4 較正の改善手法

### 2.4.1 学習を伴う手法

較正を改善する手法として，モデルの重みを更新するものがある．Li ら [19] の
ConfTuner は，確信度を適切に表明するようモデルを訓練する手法である．また
Xiao ら [20] は，事後学習によって損なわれた較正を回復させる手法を報告して
いる．これらは有効である一方，モデルの重みへの接触を要するため，商用 API
経由でのみ利用できるモデルには適用できない．

### 2.4.2 出力を後処理する手法

出力された確率を事後的に補正する手法も用いられる．温度スケーリングが代表例で
あり，Guo ら [8] が分類モデルに対して有効性を示した．LLM に対しても
Xie ら [21] が適応的な温度調整を報告している．ただし後処理は元の確信度の
順序を保つ変換であることが多く，識別能力そのものは改善しない．また補正の
パラメータを決めるための検証データが必要になる．

### 2.4.3 プロンプトによる手法

本研究が対象とするのは，モデルの重みにも出力の後処理にも触れず，入力する
プロンプトのみで較正を改善する方向である．この方向には 3 つの利点がある．
第一に，重みにアクセスできない商用モデルにも適用できる．第二に，追加の
学習コストがかからない．第三に，モデルが更新されても手法自体は使い続けられる．
黒箱環境での較正手法については Xie ら [22] に整理がある．

一方で，プロンプトによる手法は効果の上限が低い可能性があり，またプロンプトの
細部に結果が左右されやすい．どのような設計が有効かを実測で確かめる必要が
ある．

## 2.5 本研究の位置づけ

以上を踏まえ，本研究の位置づけを 3 点に整理する．

**第一に，確信度の引き出し方式の比較を日本語で行う点である．** 2.3 節で
述べたとおり，日本語を対象とした MlingConf は単一の verbalized confidence
方式のみを扱っている．本研究は Verb.1S，Verb.2S，Ling.1S の 3 方式を同一
条件で比較する．これにより，方式の違いが較正に与える影響を，条件の違いと
混同せずに測れる．

**第二に，評価に Murphy 分解を組み込む点である．** 既存研究の多くは ECE を
主要な指標としているが，2.1.2 項で述べたとおり ECE は較正の質と正答率の
高低を分離できない．本研究は Murphy 分解の信頼度成分を用いることで，この
分離を行う．予備実験の結果，この分離が実際に必要であることが確認された
（第 6 章）．

**第三に，較正の改善をプロンプト設計として扱う点である．** 2.4 節で述べた
とおり，学習や後処理による手法は適用条件に制約がある．本研究はプロンプトの
設計のみで較正を改善する方向を追求する．

なお，本研究は「日本語での較正研究が存在しない」という主張をするものでは
ない．MlingConf が日本語を対象に含めている以上，そのような主張は正確では
ない．本研究が扱うのは，方式間の比較，評価指標の選択，そして改善手法の設計
という，より限定された空白である．

## 2.6 本章のまとめ

本章では，較正の評価指標，確信度の言語による表明，多言語での較正，較正の
改善手法について概観した．ECE が広く用いられている一方で，確信度の分布に
依存する弱点を持つこと，Murphy 分解がその弱点を補いうることを述べた．また，
日本語を対象とした先行研究として MlingConf があるものの，引き出し方式の
比較は行われていないことを示した．次章では，これらを踏まえた本研究の設計
方針を述べる．
