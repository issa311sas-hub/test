# 執筆規約（秦野研究室の過去論文から抽出）

添付された過去の卒業論文3編と中間論文1編、発表スライド1編から、実際に
守られている書き方を抽出したもの。本ドラフトはすべてこの規約に従う。
Codex 等でレビューを依頼する際も、この規約を判定基準として渡すとよい。

## 1. 表記

| 項目 | 規約 | 備考 |
|---|---|---|
| 句読点 | **，および．**（全角カンマ・全角ピリオド） | 「、。」は使わない。工学系の慣行 |
| 文体 | である調 | 「です・ます」は使わない |
| 引用 | 文末に `[1]` `[2]` の番号 | 著者名を本文に出す場合は「Tian ら [7] は〜」 |
| 英略語 | 初出時に正式名称と併記 | 例: ECE（Expected Calibration Error） |
| 数式 | 別行立て、通し番号 | 変数はすべて直後に定義する |
| 図表番号 | 章番号つき（図 3.1、表 4.2） | 本文から必ず参照する |
| 節の深さ | 3 階層まで（1.1.1） | それ以上は使わない |

## 2. 章立て

過去 4 編すべてが同一の骨格を持つ。中間論文もこの骨格の前半部である。

```
要旨
目次 / 図目次 / 表目次
第1章 序論        背景 → 課題 → 目的 → 本論文の構成
第2章 関連研究     個別の先行研究 → 本研究の位置づけ → 本章のまとめ
第3章 設計方針     概要 → 各構成要素 → 評価指標 → 本章のまとめ
第4章 実装        環境 → 構成 → 各モジュール → 本章のまとめ
第5章 実験        目的 → 設定 → 結果 → 本章のまとめ
第6章 考察
第7章 結論        まとめ → 限界 → 今後の展望
参考文献
付録
```

各章は**冒頭に「本章では〜について述べる」という道案内の一段落**を置き、
**末尾に「本章のまとめ」節**を置く。これは 4 編すべてで徹底されている。

## 3. AI が書いた文章に見えないために

過去論文に実際に現れる書き方と、生成文にありがちな書き方の対比。

### 避けるもの

- **三点セットの多用**: 「高速かつ正確で、拡張性も高い」のように形容を
  3 つ並べる癖。過去論文にはほとんど出てこない。
- **空虚な強調**: 「極めて重要である」「大きな注目を集めている」
  「不可欠である」。根拠なしに程度を強める表現は使わない。
- **体言止めの箇条書きで本文を代替する**: 箇条書きは定義の列挙や
  センサーの種類など**並列で数えられるもの**にのみ使う。論の展開は地の文で書く。
- **「〜と言えるだろう」「〜ではないだろうか」**: 断定を避ける曖昧語。
  根拠があれば「〜である」、無ければ「〜は本研究では確認できていない」と書く。
- **段落冒頭の接続詞の連打**: 「また」「さらに」「加えて」で段落を始め続けない。
- **同語反復での水増し**: 前段落で述べたことを言い換えて繰り返さない。
- **メタ発話**: 「本節では詳しく見ていく」のような、内容のない前置き。
  道案内は章頭の一段落に限る。

### 用いるもの

- **具体的な数値と出典**: 「約 440 万件 [1]」「約 89% の精度」のように、
  数字は必ず出典か実測に紐づける。
- **「〜について述べる」「〜を用いる」「〜と考えられる」**: 過去論文で
  実際に頻出する定型。考察での推測は「〜と考えられる」で明示する。
- **限界の明記**: 「本研究では確認できていない」「〜は今後の課題である」。
  できなかったことを書くのは減点ではない。
- **一文一義**: 一文に主張を 2 つ以上詰めない。読点で延々とつながる文を避ける。

## 4. 中間論文としての扱い

中間論文は卒業論文の前半をそのまま使う想定で書く。したがって、

- 実験結果は「予備実験」「現時点の結果」として位置づけ、確定した結論として
  書かない。
- 最終章は「結論」ではなく「まとめと今後の方針」とし、残りの計画を具体的に書く。
- 統計的に支持されない差は、点推定だけを示して「良かった」と書かない。
  信頼区間を併記し、判定できないものは判定できないと書く。

## 5. 分量の目安（目標 30 ページ）

例年の中間報告は 20 ページ前後で、章の構成も見出し 2 階層までである。
予備実験を含むぶん厚くなるが、30 ページを上限とする。項（`###`）は使わず、
「本章のまとめ」も置かない。

| 章 | ページ | 根拠 |
|---|---|---|
| 表紙・要旨・目次 | 5 | 過去中間論文に準拠 |
| 第1章 序論 | 2 | |
| 第2章 関連研究 | 4 | |
| 第3章 設計方針 | 5 | 先生の要件で中心と指定されている |
| 第4章 実装 | 4 | |
| 第5章 予備実験と考察 | 6 | 結果・考察・限界をまとめる |
| 第6章 まとめと今後の方針 | 2 | |
| 参考文献 | 2 | 20 件程度 |
