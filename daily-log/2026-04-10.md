### ⭐ タスク 2: Zotero のインストールと初期設定（所要 1〜2 時間）

**なぜ**: 先行研究の精読を始める前に文献管理ツールが無いと、後で BibTeX 手入力地獄になる。

**手順**:
1. https://www.zotero.org/ から Zotero 7 をダウンロード
2. 無料アカウントを作成（既にある場合はログイン）
3. ブラウザ拡張 Zotero Connector を追加（Chrome / Firefox / Safari）
4. Word プラグインを有効化（LaTeX 派は Better BibTeX を追加インストール）
5. テストとして `research/literature-list.md` の B-1（Kadavath 2022）を Zotero に取り込む
   - arXiv URL からブラウザ拡張で保存
   - メタデータ（著者・年・タイトル・会議）を確認
   - PDF が自動ダウンロードされるか確認
6. タグ付けルールを決める（例: `lit/calibration`, `lit/japanese-llm`, `core` など）
7. コレクション階層を作成
   ```
   卒論/
   ├ A. Calibration 基礎
   ├ B. LLM 自己評価
   ├ C. LLM 評価ベンチマーク
   ├ D. 日本語 LLM
   ├ E. 幻覚研究
   └ F. 社会・倫理
   ```

**チェックポイント**:
- [ ] 1 本の論文が全自動で取り込めたか
- [ ] BibTeX エクスポートが `research/references.bib` と同じ書式か確認
- [ ] Better BibTeX の Citation Key 書式を `著者姓_年_キーワード` 風に設定

### ⭐ タスク 3: Kadavath 2022 の精読開始（所要 2〜3 時間）

**なぜ**: これは本研究の **直接の先行研究**。ここを理解せずに章 2 を書き切ることは不可能。

**手順**:
1. Zotero に取り込んだ PDF を開く
2. `research/lit-cards/kadavath_2022_language_models_know.md` の既存記入例を横に開いておく
3. 以下の 4 点に集中して読む:
   - **P(True) とは何か** — 第 2 章の定義
   - **ECE, Brier, AUROC の報告値** — 第 3 章の Table（再現できるか?）

4. 既存の記入例を上書きして、自分の言葉で埋め直す
5. 直接引用候補 3 箇所をピックアップ（ページ番号付き）

**精読メモの追加先**:

- 気になった箇所は `research/literature-list.md` の B-1 エントリにも一言追記

**チェックポイント**:
